📚 Library Catalogue Management System

A Java-based library management application developed as part of my Software Engineering coursework.

📌 About the Project

This project focused on developing a library catalogue application using object-oriented programming principles. The system works with different types of library records, including books, DVDs, and CDs.

The application also explored graphical user interface development using Java Swing, as well as handling structured XML and JSON data.

🛠️ Technical Summary

The application was developed in Java using object-oriented programming concepts and Java Swing for the graphical user interface.

The system was designed to work with multiple library record types, including books, DVDs, and CDs, while supporting structured data processing using XML and JSON.

✨ Key Features

  • Java Swing graphical user interface
  • Support for books, DVDs, and CDs
  • Library data processing
  • XML data handling
  • JSON data handling

🌱 What I Learned

This project gave me practical experience working with object-oriented Java programming and helped me understand how different components of a larger application can work together.

I also gained experience working with graphical interfaces and structured data formats such as XML and JSON.
